# 圆环识别时效修复

## 原8000实测结果

更新后连续60.328秒184次圆环请求全部成功，过期拒绝0次；每次均识别到完整2号圆环。网关报告帧龄最大207.204ms，检测中位数45.220ms、最大68.010ms。同窗36次设备GET确认原boot/session、故障0/0、PWM0及site_ready=false保持。此为当前静止场景时效验收，不代表三环均可作为方向锚点（3号仍被裁切），也不代表动态修正已验收。

## 原因及修改

现场预览恢复后，原8000圆环接口8次请求有4次因帧龄超过250ms拒绝。相机直接诊断显示数字识别及几何检测占用主要处理时间。分析定位数字分类器每帧反复执行旋转模板的5种平移，共数千次np.roll与全尺寸布尔掩码比较。

保留全部旧旋转模板、环绕平移定义、IoU分数、0.58相似度及0.08差值拒识规则。将平移掩码移至分类器初始化阶段预计算，按位压缩，通过查表计数求交集，使用面积恒等式计算并集。未更改相机分辨率、图像坐标、曝光、250ms门槛、底盘/机构控制或物理许可。

- 3项新增测试覆盖18组旋转/平移/噪声输入和空/满/边缘/缩放输入，与旧逐模板算法分数严格一致；未知拒识保持。
- 4张实际现场图完整Detector输出逐字段一致，包含编号、中心、分数、包围框和裁切标记。
- 原视觉迁移9项、样本工作台32项回归通过；总计44项测试。
- 树莓派同一现场图8次旧识别约141.9～143.6ms，新识别约44.3～45.9ms；完整输出相等。该比较为静态图计算耗时，不等于相机采集帧率或整机控制周期。
- 仅替换Pi视觉目录digits.py，备份原文件并核对SHA。原远端文件因CRCRLF导致空行不同，通过去文档字符串后的AST核对与原源码语义一致后替换；未覆盖其他远端行为修改。
