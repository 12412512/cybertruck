# 导航速度候选与实体按键启动

2026-10-25，当前板端GC-BASE-0.3.17。PC0低档一米已完成板端闭环，用户确认正常、约一米；独立精确尺量待补，不代表实车60秒达标。

## 离线候选

`config/navigation_candidates.json`保存独立模型候选，`tools/compare_speed.py`复用正式规划和C闭环回放。两批出发2模型由90.90秒降低到55.49秒，出发1为52.13秒。候选使用0.90m/s、300RPM、0.8m/s²、3m/s³、600RPM/s和0.09秒加速度前馈补偿；前馈时间来自合成驱动滞后，未实测。滞后模型±20%回放54.34～57.54秒，仅为模型鲁棒性证据。

保留提速失败样本：无前馈的高速候选在粗加工或暂存区域发生模型扫掠碰撞，不能采用其参考时间作为完成时间。原实车冻结路线不因模型候选而提速。证据位于output/speed-comparison。

## 按键执行链

`Control/start`为无IO状态机，59准备、60查询；绑定启动身份、会话、票据及配置。稳定松开后按下PC0，消抖30ms、PB0低有效鸣叫150ms，再产生单次启动事件。等待上限60秒，失效、STOP或会话变化取消；板端ARM也检查启动事件。默认不使能、不启动PWM。

version6独立一米直线标定，0.30/0.45/0.60m/s三档，150RPM上限，真实加速度前馈为0。保留250ms反馈、500ms保活、CAN错误锁存及偏离/超时停车。不得混入整图路线。
