# 视觉迁入与当前工作台

本节点沿用 `http://127.0.0.1:8000/#vision`，增加相机与识别页面。历史回放、实时图像、像素候选和物理成功证据分别标识。视觉代码没有串口、CAN、使能、建零、清故障或运动调用。

## 目录职责

- `pi/robot/vision/legacy/`：旧工程纯算法、四组任务码解析和圆环数字模板。仅调整包内相对导入，保留旧算法及原注释；不迁入旧串口控制器、GUI和启动脚本。
- `pi/robot/vision/observe.py`：统一单帧候选接口，包含像素坐标、配置校验值、边框格式和权限边界。
- `pi/robot/vision/camera.py`：树莓派相机专用服务，双设备独立采集线程、每设备独占、最新帧缓存；250毫秒旧帧拒绝，无设备时不猜测video编号。
- `pi/robot/web/vision.py`：原工作台回放接口和固定本机8092代理。浏览器不直接占用相机。
- `config/vision/`：树莓派现用六色/工位色/圆环配置、历史像素参考及来源校验。相机身份仍需重连验收。
- `output/vision/`：已忽略的旧现场图、完整回放结果及截图。必要摘要在本文保存，不提交大量原图。

1. 核对两只by-id设备、现有相机程序所有权及分辨率；不使用video0兜底，不启动旧的带串口视觉服务。
2. 隔离部署目录已准备为 `/home/pi/gongchuang_vision_v025`，复用树莓派既有Python虚拟环境，不覆盖正在运行的机构核心。
3. 显式运行相机专用服务：`PYTHONPATH=/home/pi/gongchuang_vision_v025/pi /home/pi/gongchuang_v0131/.venv/bin/python -m robot.vision.camera`。仅绑定127.0.0.1:8092。
4. 通过SSH仅转发8092至PC同端口；原8000页面选择实时相机，获取绑定同一帧的图像与识别结果。页面隐藏/停止预览终止请求；服务端采集所有者独立，退出服务释放相机。
5. 拔线、图像过期、错误分辨率或识别处理超过250毫秒均显示不可用。主机读帧完成时间不是曝光时间；实际采集延迟仍需验证。

## 尚未接入真实任务的部分

旧 `MaterialObserver`、`RingObserver`、`OccupancyObserver`、`AlignmentObserver` 与 `FrameEngine` 已迁入。当前页面仅呈现单帧候选，不伪造连续一致的确认。历史像素参考不得自动批准为当前工位参考；占用判断需要本次有效空场景。持料/车载三个料位/释放确认需要明天实测姿态、ROI与新帧证据，再接入正式任务账本；不能以“未检测到”代替空位或释放成功。

相机安装与对焦按用户确认保持不变；旧 `metric_calibration=null`、`metric_valid=false`、`vehicle_yaw_valid=false` 保留。毫米位置、车身朝向及视觉闭环微调仍未验收。CAN故障和机构互锁不因视觉迁入改变。
