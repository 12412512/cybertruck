# 取料—存车—取出—放置：单件离线闭环

## 实现与边界

PC原8000机械工作台新增“取料→存车→取出→放置”。工作台调用现有唯一离线核心，Transfer只编排已有Mechanism单轴/舵机动作与_pose_steps安全过渡，不导入任何串口、CAN或实车适配器，也不写真实任务账本。

来源：旧工程User/Mech/pose.c、grip.c的先收回/抬升后旋转、43mm车载候选、49/50mm取料候选、转臂83°/180°和夹爪60°/98°；三料位30°/150°/270°读取用户确认的mechanism_installation.json。放置默认49/50mm仅用于离线过渡检查，尚非地面/工位标定数据。

## 使用

1. 获取离线控制权，明确勾选仅模型确认。
2. 准备模拟基准和舵机估计。已有估计不会重新锚定；位置不在基准时仍拒绝假清零。
3. 选择车载料位、合成颜色和候选尺寸，预览完整过渡。
4. 运行时冻结配置、零点版本、步骤、摘要和演示倍率。
5. 默认在持料、存车、取出、放置四处等待“模型物料确认”。可显式勾选由合成夹具自动给出观测；均不代表实物证据。
6. 动作与模型观测分别完成后更新离线位置账本。最后收回伸缩、升降并将转臂回180°。

## 互锁与恢复

- 复用Mechanism的软限位、升降/伸缩/旋转互锁和保夹约束，每一单轴完成后才交接下一步。
- 流程在运行或等待观察时持有机构模型；不能插入手动机构动作、导航或重置底盘。
- 重复HTTP请求按现有request_id去重；观察必须绑定流程ID和当前步骤，重复或错类型不推进。
- 控制权过期、周期超时、底盘未停车、机构故障、零点/配置变化、子动作结果异常或观察UNKNOWN均取消/失败，并将相关物料位置标为UNKNOWN。
- 停止保持当时夹爪估计，不自动张爪、回零或重抓；未知状态不能直接重跑。明确重置离线夹具也不会恢复机构位置或零点。
- 输出transfer_last.json仅为模型记录，重启后未完成流程标为INTERRUPTED，不自动续跑。

## 时间与演示倍率

默认保守模型18组单件完整循环约337.74～348.42模型秒，不是实车耗时，不能据此认定比赛预算通过或不通过。页面展示原速估计，1/10/20倍仅加速模型积分，不修改实车参数；真实控制循环间隔和原模型反馈失效检查保留。

流程期限由模型动作时间×1.3加120秒观察等待构成，保持有界。倍率不会延长真实反馈250ms保护或主控保护。

## 验证与证据

- 61项相关Python回归通过；包括18种（三料位×六色）完整循环、手动观测、UNKNOWN、取消、零点/底盘/配置/周期故障、重启不续跑及网关去重。
- output/transfer/offline-cycles.json记录18组时间、四处观测和最终账本；无真实成功计数。
- 原8000页面另运行一次20倍合成夹具演示，检查四处模型事件与最终收拢。结果另保存在output/transfer/web-cycle.json及截图。
- 本轮未修改/烧录固件、未清CAN故障、未重启实车核心、未发送实车动作。
