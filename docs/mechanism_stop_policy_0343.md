当前已烧录仍为0.3.42；不得用新Objects读取旧板RAM。

## 本次修改

手动单轴与保存联调组的终点允许误差独立为1mm，覆盖到位确认、实际/目标偏差、
越过命令终点及组内完成后保持检查、下一组就绪检查。固定零点和命令脉冲账本保持，
不把残差累加到后续目标，不自动补发运动。该1mm是候选工程值，未证明抓放精度。
反向位移、另一轴意外位移、稳定锚点漂移和零点负向余量仍为原手动0.5mm；
建零、停止确认及旧自动Pose严格策略不放宽。
主机/网页显式支持.43及原.42加速度报文，并按实际固件显示终点容差。
保存版本和目标、速度、加速度未改写。已存在的PE11曲线和持续PWM保持不变。

## 仍可能中断的入口

| 范围 | 条件 | 本轮处理 |
| --- | --- | --- |
| 轴终点 | 手动终点偏差大于1mm，或期限内不能到位 | 小偏差放行；超范围/超时仍停 |
| 轴运动 | 反向位移大于0.5mm、非执行轴意外运动、速度超过命令RPM的120%加3RPM | 保留；与终点误差分开 |
| 轴命令 | 发送50ms未完成、ACK250ms未到、驱动目标与命令账本不符 | 保留，避免把未接受命令当执行成功 |
| 反馈/供电 | CAN发送失败、驱动器故障、反馈超过250ms、串口断开 | 保留；无有效反馈不能续跑 |
| 基准 | 启动/会话/零点版本变化、零点无效、负向越过软件零点 | 保留；本轮不自动重建零点 |
| 底盘 | 自动姿态要求停车，手动只免轮速微晃判定，其他停车事务/故障检查仍有效 | 不改 |
| 舵机 | PWM输出失败、执行期限、参考/版本失效、自动几何互锁 | 保留；手动流程已放宽 |
| 联调 | 任一成员真实故障、组期限、未授权并发、完成后位置或速度异常 | 终点统一1mm；真实故障停整组 |
| 主机交接 | 组身份反馈超时、完成超时、等待稳定超过3秒、帧龄250ms | 保留；1mm交接修复避免被旧0.5mm挡住 |
| Web调试 | STOP/空格、释放控制权、页面隐藏，心跳租约1.5秒到期 | 保留远程调试行为 |

输入参数越界、没有控制权或未建零等很多入口只是拒绝新请求，并不等于已在运动中停机。
正常组完成后的停稳确认属于顺序执行条件，也不能一概删除。

正式比赛应由Pi正式任务持有执行权，Web只作观察/参数入口，不依赖浏览器页面心跳。
当前保存联调仍属commissioning/manual链；旧自动Pose和正式任务整合尚未因本补丁完成。
不可宣称本候选保证比赛全程不停或已达到180秒。
