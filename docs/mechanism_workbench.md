# PC机械离线工作台

入口仍为`http://127.0.0.1:8000/`，左侧选择“机械调试”。核心无串口、SSH、CAN和烧录入口。
本轮不修改STM32固件，不连接设备；保持真实GC-BASE-0.3.11及其故障保护。

## 来源与边界

只读核对旧工程`C:/Users/RISI/Desktop/智能搬运小车/User/`：

| 旧模块 | 本轮复用内容 | 本轮未移入内容 |
| --- | --- | --- |
| `Config/mech_cfg.h`、`Mech/axis.c` | 下降/伸出为正，49/50mm范围，250ms反馈时效、基准版本及到位/稳定状态区分 | 电机ID5/6的设备收发、真实反馈和建零 |
| `Mech/servo.c` | 转臂反向359°脉宽换算，83°/180°候选，45°/s缓动上限、600ms等待 | PWM输出；模型改用连续五次曲线，不宣称逐字复用硬件控制器 |
| `Mech/grip.c`、`Mech/pose.c` | 夹爪0°观察/60°释放/98°保持，先收回抬升再旋转、逐步交接、停止保夹 | 真实抓放确认、计数及未经验证的碰撞包络 |

参数唯一来源`config/mechanism_preview.json`，标记`domain=simulation`、`physical_validated=false`。
其轴速度、加速度、料盘/夹爪缓动和碰撞阈值是离线假设，不能写回实车配置。
料盘0～270°仅沿用舵机命令域，不代表全部角度经过机械可达性验证。
三个独立料位角度等待用户补充，不从旧30°或三料位数量猜测其余角度。

## 操作顺序

1. 获取统一控制权，勾选“只作用于离线模型”。
2. 建立模拟零点：升降最高、伸缩最近端为0；每次建零递增版本。
3. 显式锚定舵机估计为180°/30°/0°。无真实PWM、实际角度保持未知。
4. 单轴：填写目标再点执行，或按住点动。升降0～49mm，伸缩0～50mm。
5. 舵机：输入目标再执行；夹爪保持后张爪需显式勾选允许释放。
6. 示教：填草稿或读取当前模型/旧候选→预览逐步过渡→保存新版本→执行选中版本。
7. 停止机构或全局停止均不自动张爪、回零、收臂。模型故障保持，须明确复位模型后重建基准。

输入、候选填入、读取和保存都不启动动作。执行选中版本要求草稿与选中版本一致。
保存文件`output/workbench/mechanism_poses.json`包含SI目标、版本、配置/目标校验和待实测标记；
保留最多100个历史版本。重启只恢复历史，不恢复有效零点或执行进度。
该文件属于本机运行数据，Git忽略；后续确认后的正式姿态应另纳入受控配置。

## 代理互锁与调度

- 所有运动先要求底盘停稳，机构运行时拒绝底盘运动。
- 启用过机构基准后，底盘运动还要求基准有效、轴收回顶部1mm内、转臂180°且无机构故障。
- 尚未初始化机构时，原底盘独立模拟继续可用；不把未知机构当成真实运输姿态。
- 转臂/料盘动作前，升降和伸缩均须在基准1mm内；料盘还要求转臂180°。
- 伸缩超过1mm时，升降至少下降45mm、转臂180°；升降移动前伸缩收回1mm内。
- 姿态过渡先伸缩回0、升降回0、转臂到180°、料盘到目标、转臂到目标，最后升降/伸缩及夹爪。
- 全步骤预检后才接受；每步执行完成及模型稳定窗口后交接。无自动轴并行。
- 单轴定距使用五次时间曲线，按最大速度与加速度安排时长；未仿真负载、间隙、夹持力及机械惯性。
- 点动采用受限加速度，松开/失焦/切页/断网请求停止，350ms未续约自动取消；普通renew不替代点动续约。
- 机构调试中的有限动作及姿态在控制权过期1.5秒时也取消；底盘自动导航原有独立调度行为保留。
- 模型反馈超过250ms或控制周期超过100ms锁存故障；普通停止和底盘重置不能清除机构故障。
- 重复请求返回原结果，旧序号拒绝，失效零点版本拒绝；结果明确区分接受、运行、完成、取消、失败。

这些互锁是可测试的软件代理，尚未证明物理防碰撞。不以600ms等待冒充真实舵机到位，
不以模型完成冒充抓取/存车/放置成功，不修改真实任务计数。

962项静态基线检查通过。浏览器实际验证单轴20mm、20mm处旋转拒绝、示教预览/保存及
20→0→2mm逐步执行、返回0、转臂83°、700ms点动松手停车；均为模型。
核心重启后零点无效、角度未知、历史版本保留且没有自动动作。
