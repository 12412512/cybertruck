# 机构手动调试模式（候选0.3.27）

用户确认采用“手动调试模式：放宽流程互锁，保留通信与范围保护”。本轮仅修改代码、离线验证及Keil编译，不连接实车、不部署Pi、不重载页面、不清故障、不烧录或动作。板端最后已知0.3.26及CAN0x800现场不变；新AXF不可用于读取旧板RAM。

## 删除的手动流程限制

- 单独升降时，不再强制伸缩轴处于收回1mm内。
- 单独伸缩时，不再强制升降至少45mm且转臂参考180°。
- 单独转臂和料盘时，不再强制两轴均收拢1mm内；料盘不强制转臂180°。
- 记录人工舵机参考时，不再强制轴处于收拢位置。
- 开启本次手动模式后，单轴和舵机的每次明确执行不重复要求通用确认框；输入和滑块仍不触发动作。
- 手动舵机完成缓动与原600ms命令稳定等待后，进入新增状态9“命令完成，实际未确认”，可继续下一项手动调试，不再卡在逐次人工确认或因此触发30秒等待超时。真实位置仍未知，未增加任何抓放成功计数。

这不是删除自动姿态的互锁。模式打开时正式55姿态调用直接拒绝；原Pose始终调用严格Axis_Begin/Servo_Begin，手动接口Axis_Manual/Servo_Manual独立选择几何策略。返回互锁模式后仍需有效的实物参考，手动命令终点不能伪造Servo_Reference；人工确认状态9仍可按原证据规则记录。

## 保留条件

故障停车、真实CAN错误锁存、50ms发送/100ms回包/250ms反馈/500ms保活、STOP抢占、会话身份/去重、Web唯一控制权及1.5s租约全部保留。单轴ACK/真实到位、反向/超速/另一轴异常移动监测、底盘停车、动作期限仍生效；仍逐执行器操作，不新增任意并行。

人工建零、有效零点版本、初始舵机实物参考仍必需。升降0～49mm、伸缩0～50mm、轴1～30RPM、转臂83～180°、料盘0～270°、夹爪0～98°范围不变，PE14不开放。夹爪释放仍需单独确认；STOP不张爪、不自动回零/收臂，不重放目标。

## 接口与Web

正式命令62载荷为操作令牌uint32、零点版本uint32、模式uint8（0互锁/1手动）、人工确认uint8（必须1），总10字节。无故障、反馈/配置/停车/人工零点有效，且当前无机构动作时才接受；切换模式本身不使能、不输出PWM或轴目标。模式仅本次会话有效，初始化及停止清零，不写持久参数。

唯一核心仅在0.3.27并显式机械调试许可下开放mode操作；ACK接受前不改变显示模式。旧0.3.26及只读核心拒绝新模式。Web在原机械页增加“进入手动调试/返回互锁模式”，进入时核对现场并勾选确认。手动模式禁用自动姿态/放行步骤。保留人工建零及记录参考两个独立准备动作。
