# 阶段1只读软件验收

日期：2026-10-24。起点为`v0.1.1-stage0-prep`，本节点标签`v0.2.0-readonly`。这是独立通信及Web的软件节点，不表示阶段0物理出口或阶段1整机通信出口通过。

## 实现与复用

- C/Python共用GC协议语义：COBS分隔、CCITT-FALSE CRC、128字节有界负载、请求关联、设备随机启动身份、会话代次、500毫秒租约和推进式保活。
- STM32新增`Comm/frame`、`Comm/comm`和`Board/port`，App只调度只读USART1。PC0只报原始输入；CAN/PWM不启动，所有运动请求拒绝。
- CubeMX新增内部RNG，沿用原48MHz PLLQ时钟，不改已有引脚。生成RNG初始化及HAL驱动；随机身份失败不使用固定备用值。
- Python控制核心与Web分为两个进程，OS锁与串口独占约束设备所有权；原子快照交换状态，浏览器不导入设备管理者。默认离线，模拟模式醒目标识。
- 只读页面显示链路、核心、固件、故障、启动/会话、错帧及保活，位姿/零点/停稳/计数均保持未接入。核心或状态过期后撤销在线。
- COBS直接改编旧雷达成功实现；唯一所有权与时效处理参考旧Web。来源、哈希和改动边界见[复用依据](reuse.md)。

## 未验证及边界

- 未连接物理UART、未烧录、未执行SWD、未部署树莓派、未操作CAN/PWM或触发运动。
- 主机调用正式C状态机不包含HAL、中断和真实串口时序；UART收发/故障恢复、RNG时钟及真实复位行为仍需板端验收。
- STOP只验证独立应答槽和禁止标记，不声称实际停车；运动动作ID去重、设备截止时间、动作完成证据在后续动作阶段实现，当前运动类型均拒绝。
- 只读页面仅实现总览和协议诊断；地图、机械调试、姿态示教、参数生效、视觉、任务与日志回放页面留给对应阶段。
- 启动身份隔离不是加密认证；当前Web默认绑定127.0.0.1。内部部署及访问权限随实机接入设计。
- 完整收拢/运输包络、机构全行程、雷达覆盖和180秒预算仍待阶段0实测；本节点不依赖这些数据，也不修改其待验证状态。
