# 机械实测与保存清单

本清单接在已保存P00～P07之后。0.3.37仅PE11使用S曲线，PE9、PE13按所填速度匀速步进。开始、结束的运输姿态已确定为升降0mm、伸缩84mm、料盘0°、转臂0°、夹爪0°；夹持98°、松开60°、相机观察0°。已有参数不重复量，不擅自修改。

## 烧录后的准备

确认固件为0.3.37及新鲜无故障停车反馈。由用户获取控制权、接入机构反馈；人工确认升降最高、伸缩最近端后建零，再进入手动调试。不能在伸缩84mm运输姿态直接把它建成最近端0mm。舵机按当前实物核对参考，或由用户执行三路命令0°并目视确认建立参考；首次未知位置回零不保证慢速。

先各验证一次PE11平滑转动、PE9和PE13按速度执行，确认方向、停止和线缆；由用户在网页执行，软件不自动下发验证动作。

## 按顺序补齐的动作

每个新版本记录一个明确的小阶段，写清它从哪个已知姿态开始。单项先通过一次，再验证同组并行；最后把完整单件循环连续做3次。表中名称仅为便于查找的示例，不强制改已有版本名。

| 顺序 | 实测内容 | 建议保存的阶段/名称 | 需要核对 |
|---|---|---|---|
| 1 | P07退出后恢复运输 | P08_退出后收拢 | 实际回到前五项姿态，料位中的物料保留，整个过渡无干涉；不是只核对终点 |
| 2 | 从30°料位取回 | T30_预取、T30_夹持、T30_抬离、T30_取出避让 | 抓取前对准，98°夹持后再抬离；实际取出、车槽变空；携料避让时保持夹持 |
| 3 | 150°料位完整存取 | S150_预存/释放/退出；T150_预取/夹持/抬离 | 可复制已测版本作草稿，再核对实际伸缩、转臂和高度；相同项直接复用，不重测无关参数 |
| 4 | 270°料位完整存取 | S270_预存/释放/退出；T270_预取/夹持/抬离 | 同上，检查转盘换位时夹爪、杆件和线束的整个路径 |
| 5 | 粗加工圆环放下并取回 | R_观察、R_预放、R_释放、R_退出；R_预取、R_夹持、R_抬离 | 先测一个环的完整放取；其余两个环若高度/停靠关系相同，仅验证复用，不重复建立相同姿态 |
| 6 | 暂存第一层平放 | F1_观察、F1_预放、F1_释放、F1_退出 | 保留真实第一层物料，核对释放后的稳定性和相机可见性 |
| 7 | 第二层同色码垛 | F2_观察、F2_预放、F2_释放、F2_退出 | 用真实第一层作支撑；单独测层高和退出路径，不能照搬地面高度 |
| 8 | 携料运输与工位进出过渡 | 携料避让→存车→运输；运输→各工位观察 | 行驶前物料存车、机构在运输包络；手里持料时不能盲目执行含松爪/观察0°的整表 |

不要求一次扩大到完整机械极限行程，只记录这些真实任务动作所需的最大下降量、最大伸出量及已验证余量。底盘本轮不自动运行，先完成固定车体的机构调试。

## 一起运动怎么保存

- 现在就在联调表调好并保存：相同顺序号属于同一并行组，不同顺序号依次进行；前组全部完成才进入下一组。
- 例如已由用户验证的P07末组，升降0mm和夹爪0°都用顺序16。此时物料已在前一组用60°释放，不能把该组套到仍夹持物料的阶段。
- 同一执行器的两个目标不能放同一组；跨多组重复同一执行器属于正常顺序动作。
- “全部同时执行”只适合每个执行器最多出现一次的短表。P07这种累计长表含重复执行器，不能整表全部同时。
- 同组意味着一起启动并等待全组结束，不代表严格同毫秒启动或同时到位。当前页面不支持任意毫秒错峰或强制同时到位，不用改速度假装已具备此功能。
- 未验证过的组合先分组通过，再从低速验证并行路径。输入或保存版本不会驱动实车，点击执行才发送请求。

调好保存后，无需抄录全部参数。请只告诉我“哪些版本/修订已实物通过、起始姿态、异常现象或本次循环耗时”；目标、速度、顺序和同组关系由我读取。失败版本保留，修正保存新修订。

P00～P07原表是累计检查点，仍保留用于调试；正式程序读取来源ID/修订/SHA后提取新增动作，不会把这些整表逐个重跑。新的阶段表也按明确起点衔接，未经实测不自动挂入比赛路线。

## 顺手保存的视觉证据

相机在线时，在“相机与标定→实时相机→物料相机”保存当前新帧；关联刚执行的机械版本，填写观察工位、料位、颜色、人工标签和备注。每个结果先保存正反例各一组，不必每次重复采相同画面。

| 状态 | 最少保存内容 |
|---|---|
| 原料观察/预抓 | 目标存在、目标偏位或不可抓取的反例；抓取中心可见 |
| 原料抬离 | 确实持料、空抓各一组 |
| 三个车载料位 | 每槽空位、存料后、取出后三种状态，保持同一个可复现观察姿态 |
| 粗加工放取 | 正确放置、偏位/错误目标、取回后空位；圆环号码仍需可辨认 |
| 第一层暂存 | 释放后稳定图、偏位或遮挡反例，记录颜色到位置的实际对应 |
| 第二层码垛 | 第一层顶面、第二层释放后、偏斜/不稳定的反例 |
| 几何校准 | 原料台、地面、车载料位、码垛顶面分别保存；旧安装和配置可复用项先复核，不混用平面 |

相机没在线时先完成机械版本；稍后恢复同一观察姿态补图，不用重跑全部取放。不能用旧帧、计时完成或人工标签自动增加抓放成功数。

## 一轮结束后告知内容

建议一次回复：`已通过：版本名/修订；并行组：顺序号及成员；完整循环：第1/2/3次耗时；异常：无或具体现象`。我会直接读取当前Web/Pi保存数据，再完成增量编排、视觉确认与正式任务账本接入。
