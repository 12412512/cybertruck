# 自主规划到执行器：PC离线接入

2026-10-25完成本节点。沿用原`http://127.0.0.1:8000/`，没有连接树莓派、串口、SWD或相机，没有烧录、清故障或实车动作。

## 接入方式

工作台当前计划（包含启停区、障碍物、工位间隙和速度）→复查计划版本/场景/完整车体扫掠→`nav.bridge.prepare`冻结目标包→`drive_core.run_trial`→内存传输→正式C的`Comm/Start/Execute/Exec/Ref/Track`→独立轮速/编码器/IMU模型→协议反馈。

- 复用原执行链的单会话、一次配置/使能、递增动作ID、连续里程计、段间停车交接及末尾STOP；合成PC1选区和PC0按键经过正式选择/去抖/短鸣等待状态机。
- 计划包携带源计划ID、场景/参数、目标摘要及边界，不直接信任浏览器上传的裸目标。载入前重新检查保存计划、参考段和配置一致性。
- 当前入口限制0.30m/s、100RPM、加速度≤0.25m/s²、加加速度≤0.8m/s³；1～64段，单段参考≤25秒。普通模拟仍可研究更高参数，不能通过此入口提升实车上限。
- 250ms反馈过期、500ms保活、CAN故障、偏离、超时、启动状态和停车判定复用正式代码。独立Plant每2ms检查整车扫掠，不用目标中心线代替外形。
- `EXEC_PREVIEW`仅在主机测试库定义，动态目标加载不进入板端固件。真实串口路径继续只接受已冻结路线，不能装载`planned_preview_v1`。
- 合成模型没有USB抖动、真实CAN仲裁/电气时序、轮胎打滑、载荷及相机定位误差；本轮通过不等于自主导航实物验收。

## 原页面使用

1. 获取控制权，选择起点、工位、障碍物和0.30m/s/100RPM档，生成路线。
2. 点击“执行链联调（合成PC0）”。此按钮自动产生模型按键，不需要也不应按实物PC0。
3. 地图紫线显示协议执行器模型轨迹，反馈卡显示这一独立模型的时间、误差与故障。普通模拟和实车状态不被覆盖。
4. 完成应显示`COMPLETE`、全部段完成及“模型STOP已确认”；取消、失去控制权、故障或断线不重放、不自动续跑。联调时拒绝机构动作、点动和改路线。

草稿/路线沿用`output/workbench/workspace.json`，每次联调包、完整事件和报告归`output/workbench/execution_checks/<任务ID>/`，摘要为`execution_check.json`；重启中的未完成任务标为INTERRUPTED，不自动运行。
