# 硬件配置基线

本表的初始验收段为历史基线。2026-10-25新增PC1选区候选，当前软件与实车边界见[PC1选区记录](zone_switch.md)；不能用下列历史状态替代当前实物验收。

2026-10-24只读软件阶段仅新增内部RNG，用PLLQ的48MHz时钟生成每次启动身份；不占外部引脚。USART1启用中断收发，USART2/6仍不启动采集/发送，CAN和PWM仍不启动。

| 项目 | 配置目标 |
| --- | --- |
| MCU | STM32F407ZGT6，LQFP144 |
| 时钟源 | HSI 16 MHz，经 PLL 输出 SYSCLK 120 MHz |
| PLL | M=16，N=240，P=2，Q=5 |
| AHB/HCLK | 120 MHz |
| APB1/PCLK1 | 30 MHz，分频 4 |
| APB2/PCLK2 | 60 MHz，分频 2 |
| APB2 定时器时钟 | 120 MHz |
| 调试 | SWD：PA13/PA14 |
| 工程 | `Car.ioc`，Keil 工程与单 Target 均为 `Car` |

## 引脚与外设

| 引脚 | 功能 | 配置与用途 |
| --- | --- | --- |
| PA9 / PA10 | USART1 TX / RX | 树莓派，115200、8N1 |
| PA2 / PA3 | USART2 TX / RX | IMU，115200、8N1 |
| PC6 / PC7 | USART6 TX / RX | TJC 屏幕，115200、8N1 |
| PA11 / PA12 | CAN1 RX / TX | 电机总线，500 kbit/s |
| PE9 | TIM1_CH1 | 料盘 PWM |
| PE11 | TIM1_CH2 | 转臂 PWM |
| PE13 | TIM1_CH3 | 夹爪 PWM |
| PC0 | GPIO 输入 | 启停按键，上拉、低有效，后续软件消抖 |
| PB0 | GPIO 输出 | 蜂鸣器，低有效，初始化输出高 |
| PC1 | GPIO 输入 | 内部上拉；公共端接PC1，低/GND选区1、高/断开选区2，稳定50ms；候选0.3.20待烧录实测 |
| PA13 / PA14 | SWDIO / SWCLK | 保留下载与调试 |

PA11/PA12 已分配 CAN1，当前不启用占用同引脚的 USB 功能。

## CAN1 参数

APB1 为 30 MHz；预分频 4、BS1=12 TQ、BS2=2 TQ，单比特共 15 TQ，得到 500 kbit/s。自动重发关闭；正式通信阶段再按唯一调度器配置过滤器和启动接收，最小工程不启动电机通信。

## PWM 参数

TIM1 时钟 120 MHz，PSC=119，计数周期 1 μs；ARR=19999，输出频率 50 Hz。三个通道的初始比较值均为 0。

CubeMX 初始化通道，但最小工程不调用 PWM 启动，不把初始化视为舵机位置命令。脉宽映射及机械限位后续逐项标定。
