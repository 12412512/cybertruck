## 引脚与外设

| 引脚 | 功能 | 配置与用途 |
| --- | --- | --- |
| PA9 / PA10 | USART1 TX / RX | 树莓派，115200、8N1 |
| PA2 / PA3 | USART2 TX / RX | IMU，115200、8N1 |
| PC6 / PC7 | USART6 TX / RX | TJC 屏幕，115200、8N1 |

| PE11 | TIM1_CH2 | 转臂 PWM |
| PE13 | TIM1_CH3 | 夹爪 PWM |
| PC0 | GPIO 输入 | 启停按键，上拉、低有效，后续软件消抖 |
| PB0 | GPIO 输出 | 蜂鸣器，低有效，初始化输出高 |
| PC1 | 暂不启用 | 启停区在网页选择 |
| PA13 / PA14 | SWDIO / SWCLK | 保留下载与调试 |

PA11/PA12 已分配 CAN1，当前不启用占用同引脚的 USB 功能。

## CAN1 参数

APB1 为 30 MHz；预分频 4、BS1=12 TQ、BS2=2 TQ，单比特共 15 TQ，得到 500 kbit/s。自动重发关闭；正式通信阶段再按唯一调度器配置过滤器和启动接收，最小工程不启动电机通信。

## PWM 参数

TIM1 时钟 120 MHz，PSC=119，计数周期 1 μs；ARR=19999，输出频率 50 Hz。三个通道的初始比较值均为 0。

CubeMX 初始化通道，但最小工程不调用 PWM 启动，不把初始化视为舵机位置命令。脉宽映射及机械限位后续逐项标定。
