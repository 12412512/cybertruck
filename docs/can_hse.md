- PH0/PH1配置为HSE晶振模式，PLL由HSI改为HSE，HSE_VALUE从25MHz改为实际8MHz。
- PLL M=8、N=240、P=2、Q=5：SYSCLK/HCLK仍120MHz，APB1仍30MHz，APB2仍60MHz，PLLQ仍48MHz。
- CAN仍500kbit/s，采样点86.67%；TIM1仍50Hz，四路初始脉宽0；UART与SysTick名义节拍不变。
- CubeMX原有HAL时钟失败分支进入Error_Handler，在初始化CAN、TIM和App之前停住；没有增加HSI回退。检查器及负例测试覆盖错误源、25MHz声明、旁路模式和失败分支被破坏的情况。这是源码/离线验证，不代表已测试实物晶振起振。
