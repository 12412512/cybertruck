# 两批导航连续段优化

2026-10-25按用户要求暂停机械动作，回到PC底盘模拟优化。本轮不访问设备、不烧录、不清故障、不执行实车动作。实车CAN问题仍保留，不因离线路线通过而解除。

## 改动

1. 同一工位间的捷径组合由局部最大收益改为动态规划，在已生成且检查通过的候选中选择剩余总耗时更短的组合。原始段始终是可选回退；不跨越扫码、取放等任务停靠点，不声称连续平面全局最优。
2. 补上“短直线出站＋同一直线上的路口转姿窗口”合并候选。保留原窗口的地图位置和宽度，整段重新经过正式C参考、轮速界和完整车体扫掠检查。
3. 跨工位C float产生约0.1微米舍入时，原共线候选筛选可能漏掉上述合并。共线叉积筛选改为与既有直线合并一致的1e-6数量级；这是候选生成筛选，不改变碰撞余量、field.check精度或执行保护。
4. 原8000工作台增加60秒预算分解，区分参考运动时间和每段停稳预留。原速度、工位间隙、障碍和历史版本保留；页面脚本更新至v4。旧已保存路线保持原内容，新策略需重新规划才能应用。

模型共用正式Ref/Track/Odom，运行时独立检查2ms真值扫掠；反馈、超时、偏离及碰撞保护保留。没有靠缩小车体、取消工位停靠、降低停车完成要求或提高速度获得上述收益。
