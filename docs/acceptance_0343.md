## 随后：固定观察基准和单件完整闭环

| 在当前Web保存 | 实物操作与说明 | 用途 |
| --- | --- | --- |
| 原料观察姿态的新联调版本 | 选一个真实成功抓取位置，固定底盘和目标平面；记录两轴/三舵机全部目标 | 绑定随动相机姿态；不假设图像中心为夹持中心 |
| 对应视觉样本 | 关联上述版本ID/修订/SHA，保存目标颜色、ROI、实际能抓取的像素位置；注明实测成功 | 建立期望图像位置 |
| 小位移对照样本 | 等软件根据可用画面安排两独立方向的少量已知位移及独立检查点，再由用户执行并保存 | 测局部映射，之后才选择底盘或机构微调 |
| 一个槽位取出→放置的联调版本 | 优先补未确认的取出/放置，不重做三槽存入；固定已编号圆环 | 完成单件闭环，连续3次记录成功与耗时 |
| 空抓/持料/释放后样本 | 每种状态关联正确姿态；人工标签只作证据，不自动增加成功数 | 验证识别确认，避免命令完成冒充抓放成功 |

相机随ID5、ID6、PE11、PE13全部运动；改变其中任一观察姿态、相机安装或目标平面，原局部映射不自动沿用。
保存时设备快照不是曝光时姿态，采样应在保持同一姿态的稳定期间；软件不能将这一快照冒充同步曝光证据。
原料按任务码选择目标颜色和可达观察窗口，不固定为一个抓取方向；先标定一个窗口，再扩展其他方向。
