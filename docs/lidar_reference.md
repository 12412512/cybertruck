## 实际使用方式

雷达是带自身处理与预设场地位姿的模块，TTL电平3.3V、5V供电、共地，115200/8N1。手册适用固件1.35/协议6，旧工程曾核对1.37/协议6；换板后仍需实际HELLO读取，不能当成本次在线版本。

| 功能 | 手册命令 | 当前复用边界 |
| --- | --- | --- |
| 握手、500ms保活 | 01、02 | 旧驱动已支持 |
| 连续扫描、停止 | 03、04 | 旧静态流程用有界连续扫描并显式STOP |
| 切换启停区及保存 | 05、13 | 旧驱动已支持；ACK后还需匹配HELLO确认当前区 |
| 单次锁定扫描 | 07 | 厂家能力，旧COMMANDS白名单尚无此命令 |
| 栅格扫描 | 08 | 厂家能力，旧驱动尚未接入 |
| 内部栅格路径规划 | 14 | 厂家能力，依赖有效持久栅格结果；旧驱动尚未接入 |
| 点云输出开关 | 19 | 旧驱动已支持，显示点云最多120个抽样点 |

07/08通常等待14圈扫描及最终完整结果；不能把ACK当扫描完成，也不能把有效空结果和“尚未扫描”混为一谈。内部规划只作参考，不能替代本车带朝向和整车包络的规划器。抽样点云不等于完整LaserScan，模块保存的位姿不等于移动小车的实时定位，不能直接当SLAM。

旧静态方案采用约10秒有界连续扫描，区分云序号与栅格/结果序号、校验GRID/RESULT配对/数量/溢出，结果短期有效，并显式停止；不能直接套成07单次流程。旧`cyqm_field`尚未与地图配准，前方有遮挡；右侧近物A/B71帧响应与0基线是局部检测证据，不是道路坐标标定或全场覆盖。

## 新工程接入顺序

1. 用离线报文夹具移植已有解码器/有界缓冲/帧序号/完整性检查，补07/08及完成状态，保持雷达唯一所有者；与STM32串口区分。
2. 在已知停车姿态执行一次有界扫描；两启停区分别标定。车辆PC1区号不能不经核对就映射厂家区号，也不能简单镜像外参。
3. 只有扫描覆盖、结果完整、时效与标定版本有效时，才将障碍几何转换到地图并更新道路。未知/遮挡保留未知，零障碍不自动表示全场开放。
4. 将观测转换成当前工作台使用的障碍模型，复用同一规划器→本轮离线执行链；保留观测来源和路径版本。
5. 新PCB验收及停车实扫通过后再申请实车接入。运行中不沿用停车预设位姿解释新扫描；异常先停车，不在未知区域自动绕行。

本轮没有把手工黑圈当成真实雷达观测，也没有开放雷达自主封路或动态路线实车执行。
