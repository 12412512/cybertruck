# 阶段0：测量项目与方法

本阶段回答三个问题：现有机构能否覆盖全部抓放高度和距离；车辆能否在真实车道内通过和转向；现有器件与动作路径是否具备180秒完成的可能。此文是操作与记录准备，不表示已完成实测或整机验收。

先完成A组断电静态测量，再完成B组只读观测，最后安排C组受控动作。通电前核对当前固件、故障、位置、零点及断电/复位/手动移动历史；旧日志中的零点和停车状态不作为当前有效状态。

## 1. 工具、基准和记录规则

- 使用已有钢尺/卷尺、卡尺、直角尺、纸胶带、笔和手机计时/录像即可；临时测量工具不安装为车载传感器。没有某种工具时注明量具和估读范围。
- 在车体固定、不随机构运动的部位贴出车头和一个可重找的基准点。新工程车体方向为X前、Y左、Z上；俯视逆时针为正。旧工程向右为正、顺时针为正的读数保留原字段，由迁移适配层转换。
- 建议平面原点采用四轮轮心投影所成矩形的中心，Z=0采用平整地面。在车架上做可见定位标记，记录标记到原点的偏移。若四轮不对称，记录各轮坐标，不强行当作完美矩形。
- 尺量沿水平/竖直方向取投影距离，不能以斜放的卷尺读数代替。每次从同一固定面、同一活动件标记读取；不以机构滑轨总长代替活动件行程。
- 普通关键尺寸独立重复读取3次，保留原始读数、量具、最小刻度和估计误差。车道净空采用最小实测值，外形采用最大实测值；不能用平均数掩盖最窄处或突出物。
- 下文建议的1毫米、5～10毫米等是测量/分段准备尺度，不是控制精度承诺，也不直接成为软限位或停车阈值。无法分辨的读数标明约数，不补小数。
- 每条记录包含日期、安装版本、载荷、机构姿态、测量基准和证据编号。安装、轮胎、机构基准或载荷改变后，标记受影响的数据待复核。
- 人工回填用毫米、度、秒；后续入正式配置时统一转为米、弧度、秒，并保留原始读数。未知写“待测”，不写0。

## 2. A组：断电可完成的静态测量

断电检查只观察、尺量当前可访问部位。不强推自锁机构、不扳舵机、不转动电机来寻找极限；已有姿态无法安全摆出时留待C组。

| 编号 | 需要的数据 | 具体方法与回填内容 | 用途 |
| --- | --- | --- | --- |
| A1 | 收拢外形 | 车放平地，在当前确认的收拢姿态量最大长×宽×高。两把直角尺或竖直挡板贴近最外缘后量间距；包含夹爪、屏幕、支架、插头和自然伸出的线束。标明当前是否确实为出发姿态 | 判断启停区容纳和初始包络 |
| A2 | 运输及载物外形 | 按同样方法记录运输姿态空载、三个料位均载物时的外形。用形状和尺寸相同的实物，记录最高/最外突出点。现有姿态不可达则待C组，不强行摆放 | 载物通行和碰撞轮廓 |
| A3 | 外形相对车体原点的边界 | 分别量原点到最前、最后、最左、最右的水平距离。外形可能偏心，只有长宽不足以正确检查转弯扫掠。另列机构作业时的包络，和运输包络分开 | 规划器实际轮廓及转弯检查 |
| A4 | 底盘几何和轮型 | 量前后轮轴中心距、左右轮中心距、四轮外径；胶带记FL/FR/RL/RR并记录滚子倾斜方向。外径在多个方向读取，压缩量/有效轮径后续用行驶尺量校准 | 麦克纳姆几何初值，不能替代运动标定 |
| A5 | 升降、伸缩结构 | 指明ID5/ID6实际对应轴、固定面、活动件测点、预期正方向、机械挡块、实体限位开关及线束限制。记录人工基准姿态的可重复机械特征。当前可见滑轨长度仅作结构信息，不据此给完整行程 | 建零、分段行程验证准备 |
| A6 | 三个料位的几何 | 自定并贴签S1/S2/S3；量各槽有效开口、底面高度、槽中心、槽间距。料盘若旋转，则同时记录旋转中心、零位标记和各槽相对料盘的中心；不要把转过后的槽位置混为同一车体坐标 | 三槽存取、占用状态与观察ROI |
| A7 | 物料实际尺寸 | 按实际使用的颜色/形状记录最大宽度、长度或外径、高度及上下接触面；同类至少检查3件，有多少实物就写多少。有码垛形状时量下层顶面和上层底面能否稳定接触。有秤可补质量，没有则待测 | 抓取开口、载物轮廓、层高和精度评估 |
| A8 | 相机与雷达安装 | 两相机分别记用途、镜头中心相对原点的X/Y/离地Z、朝向及支架是否牢固；粗量朝向仅作初值。雷达量实际扫描平面离地高度、扫描中心X/Y、朝向及四周遮挡，不以外壳底面高度代替扫描面。无法确定扫描平面时标待厂家尺寸核对 | 感知安装可行性，正式外参另行标定 |
| A9 | 最窄车道及转向区 | 每条拟用道路在入口、中部、出口和突出物处量净宽；边界取规则禁止越入区域的真实边缘，不默认把线宽计入可行驶区。记录路口完整可用多边形、转向区宽和长，以及障碍物侵入后的净空 | 车体扫掠、路线选择和无路判断 |
| A10 | 两个启停区 | 两区分别量边界、长宽、相邻通道开口；标出车体原点计划位置和车头方向，并量到两条固定边的垂距。记录可重复摆放的标记。两个起点独立量，不从一个起点简单镜像 | 初始位姿和返航配置 |
| A11 | 工位和目标高度 | 量原料台面离地高度及边缘、转盘中心/半径、粗加工和暂存作业面高度、各编号圆环中心/间距、边缘至车道距离。码垛顶面高度按实际下层物料测量。随机二维码板/原料盘的位置按当次记录，另记允许范围 | 各目标平面和机构可达性 |
| A12 | 设备和供电清单 | 记录树莓派/IMU/雷达/两相机/电机驱动器型号、供电标签、已有电池容量标签、供电分支及接头；暂不拆电路或带电测不熟悉的端子。记录STM32串口连接形式和是否另有程序会占用 | 设备绑定和后续日志诊断 |

### 场地坐标怎么量

选择两条相互垂直、可以复找的固定边作为地图X/Y基准，标明原点和正方向。先画俯视草图，再按角点编号记录可行驶区、禁行区、路口和启停区；圆环中心既记坐标也记现场编号。车体坐标与地图坐标分开，不要求两者在所有工位都同向。

暂时没有完整赛场时，先回填车体、机构、物料和已有工位。名义场地可用于软件预览，未量道路继续标“待测”，不标已验证可通行。

以290×270毫米矩形为例，绕其中心原地旋转的角点扫掠直径约396毫米。这仅说明400毫米宽处几乎没有余量；真实转弯还要用A3的偏心轮廓、转心位置、定位误差、线束和载物包络检查。不能以对角线小于车道宽度就认定允许转身。

## 3. B组：核对设备后，只读观测

此组由我先核对现有固件及服务，复用旧相机/雷达只读入口；不让用户凭文件名猜测可执行入口，也不启动可能自动使能电机的旧服务。当前新工程没有相机、雷达或下位机业务运行入口。

### B1. 当前设备状态

先记录树莓派地址、用户名、已有免密登录方式（不在文档记录密码/私钥），STM32固件标识、串口设备身份、当前故障、轴位置、反馈时效及零点状态。补充最近一次断电、复位、烧录和手动移动发生在何时。型号/路径由只读枚举协助获取，不要求用户重新手抄全部系统信息。

### B2. 双相机视野与可观测性

1. 固定当前相机安装，记录实际设备身份、分辨率、帧率、曝光配置和安装版本。优先复用已有采集所有权及最新帧缓冲，确认无第二程序抢占。
2. 扫码相机：在实际二维码板位置范围的近端、中间、远端和两侧位置检查完整码是否可见；记录距离、高度、倾角、眩光/遮挡和最慢识别时间。测试码与正式任务码分开。
3. 物料相机：分别观察原料平面、地面/工位圆环、S1/S2/S3空槽与有料槽、夹爪持料区域、第一层物料顶面。在现有安全姿态无法看见的区域先标“不可见/待调整”，不触发轴运动凑视野。
4. 在每个目标平面平放带已知间距的网格纸或尺，记录中心与四角的可见范围（毫米）及遮挡位置。倾斜相机不能用一个中心像素比例代替整幅图的映射；此步只验视野，阶段4再完成内参/畸变/外参和多平面标定。
5. 手工放入物料可验证槽位可见性和识别正反例，但不计为机器人成功抓取/存车。黑料与阴影、蓝与浅蓝、半遮挡目标分别留样。
6. 采集链路延迟由软件记录并结合手机录像中的外部可见变化估计端到端上界；若相机不提供曝光时间戳，要明确“主机read返回时刻不等于曝光时刻”，不宣称精确测得曝光延迟。

输出一张“目标平面/姿态—看得见哪些目标—能否可靠分辨—盲区—证据”表。姿态变化后的可见性在C组补齐。

### B3. 雷达覆盖

1. 先记录扫描平面真实离地高度和倾斜；用实际比赛障碍物验证扫描面能穿过其侧面。不仅检查近处：低装雷达稍有倾斜也可能在远处越过低障碍。
2. 在启停区1，保持小车已知位置和朝向不动，用胶带标出已测障碍位置，依次覆盖拟用道路的近、中、远处及可疑盲区。每个位置采“无障碍→有障碍→移走”对照，使用新扫描编号和完整结果。
3. 记录每次障碍相对固定场地基准的坐标、尺寸、朝向、是否被车体遮挡；保存识别结果与完整性状态。多圈重复观察后仍不稳定的地方标“未知”，不因没有回波而填“道路开放”。
4. 在启停区2按独立姿态重复。相机/雷达安装调整后重新验证受影响区域，不沿用之前的外参或遮挡结论。
5. 只统计经过原始数据和实物对照的检出；厂家格子候选不等于实际道路坐标，也不等于障碍物数量。当前静态雷达接口不承担行驶中定位。

阶段0至少得到必要道路“可直接观察/需停车补扫/仍有盲区”的覆盖图；地图配准、封路算法和完整扫描自动流程在后续接入，不能提前写通过。

## 4. C组：后续安排的受控动作测量

这组先给出方法，当前不执行。开始前明确实际固件入口和该入口每次按键含义；保留人工逐步触发、停车后读回。不要自行按旧PC0试探，因为旧入口下一步可能是转臂或其他动作。

### C1. 人工基准与完整可用行程

1. 在可支撑机构的状态下按明确步骤置于人工基准，拍下/画出固定面与活动件标记。确认反馈静止后建立本次软件零点，记录零点版本；不向驱动器写永久零点。
2. 同一时刻只测一个轴，另一个轴和舵机保持已确认的避碰姿态。固定尺不进入行程；每个位置在停稳后读尺，记录目标、编码器换算值、独立尺量值、另一轴位置和异常。
3. 先复核已有短行程和49/50毫米工作点。安装和传动没变时，可用少量代表点复核旧换算，不重复所有历史调试。
4. 超出已验证范围前先检查剩余机械净空和线束，再为下一小段设置临时边界。建议准备5～10毫米级分段方案，接近受限处进一步缩小；实际步长取决于可见净空，不能盲目按固定步长探限。
5. 在明显碰撞、线束拉紧、皮带/丝杆受限之前停止；不以撞机械挡块、堵转或拉紧线束寻找最大行程。分开记录“结构可能范围”“本次实际验证范围”“保留余量后软件允许范围”。余量由重复性、停车距离和几何共同决定，不先写死一个通用值。
6. 在候选工作位置至少往返3次，从相同基准读数，保留出程/回程差、零点回差和最大偏差。空载验证后再安排实际物料负载，不用空载数据证明满载稳定。

历史145/107毫米只是待复核的可用行程报告；历史49/50毫米也不等于所有转臂/料盘姿态下均无碰撞。实际任务可能在到达轴极限前就受到夹爪、车架或相机遮挡限制。

### C2. 夹爪中心、三槽姿态与工作高度

对出发收拢、运输、工位观察、原料预抓/抓取/抬离、三个料位各自存入/取出、粗加工地面放取、第一层放置、第二层码垛逐一记录：

- 两轴相对人工零点的位置、转臂/料盘/夹爪命令值；普通PWM命令角度列名明确写“命令”，不写实测角。
- 夹爪抓取中心相对车体原点的X/Y/Z、物料底面高度、观察视野、最近碰撞物及其净空。
- 该姿态的安全进入与退出顺序。端点无碰撞不证明过渡路径无碰撞；料盘转动和转臂摆动单独检查扫掠空间。
- S1/S2/S3分别验证；夹持相同物料时至少做3次重复观察/抓放，记录偏差、掉落或遮挡，不能只凭一槽推定其余两槽有效。

先以实际工位目标高度检查可达性，测出满足任务所需的最小行程；不为追求大行程而扩展无用范围。第二层高度以实际下层物料顶面和夹爪接近路径为准，不能只把轴目标机械加一个名义物料高度。

### C3. 动作耗时与180秒预算

将24次外部取放按四种类别计时，每类在实际需要的目标高度/料位/层数下取样；初测每种代表组合至少3次，失败和恢复也记录，不只取最好的一次。

| 类别 | 每轮次数 | 计时起点 | 计时终点 |
| --- | ---: | --- | --- |
| 原料→车载槽 | 6 | 底盘已停稳、允许本次预抓动作 | 正确物料已确认存车、夹爪退出并恢复本次后续动作要求的姿态 |
| 车载槽→粗加工 | 6 | 底盘已停稳、允许本次取出动作 | 正确目标处已确认释放、夹爪退出并恢复所需姿态 |
| 粗加工→车载槽 | 6 | 底盘已停稳、允许本次再抓动作 | 正确物料已确认存车、夹爪退出并恢复所需姿态 |
| 车载槽→暂存/码垛 | 6 | 底盘已停稳、允许本次取出动作 | 前3次确认第一层放置、后3次确认同色码垛，夹爪退出并恢复所需姿态 |

采用连续时间线记录发令、接受、运动、到位、视觉确认、运输姿态和下一动作开始。未实现的确认步骤写“未接入”，不以人工确认时延或固定等待冒充最终视觉耗时。

“取→存→取→放”连续完整循环可用于快速筛查机构时间可行性，但不能仅测一个物料循环就乘12作为整轮结论：不同槽、不同平面和码垛路径耗时不同。抓取/放置计数仍按独立真实事件确定。

初始机构预算95秒，分给24次外部转存平均约3.96秒/次；等价的12组取存取放平均约7.92秒/组。这只是预算约束，不是现有能力。阶段0先用少量代表实测得出可行性初判，阶段3完成三槽与工作姿态后细化；若已明显超预算，先调整动作路径/安装/经过验证的速度档。

全任务预算为导航60秒、机构95秒、不能重叠的扫描/扫码/视觉等待10秒、余量15秒。导航计时应包含起步加减速、转向、停车和工位进出。以后把可并行采集按同一时间线算关键路径，既不重复扣时，也不遗漏串行等待。

### C4. 底盘时间可行性与停止距离

阶段0只做受控代表性初测，不承担阶段2的完整控制标定：在经过尺量的宽敞合法空间，选择已确认的固件/速度档，记录固定距离的前进/后退、必要90度转向、工位短侧移的实际距离、角度和从启动到停稳的时间。每种代表条件至少3次，空载/三件载荷分开；未验证速度档不直接用于试跑整条路线。

车架上设置两个固定标记供测朝向，测起止标记线相对地面固定线的角度；可用俯视录像作辅助，保留相机透视误差。不能只用IMU自身读数证明IMU正确，也不能只用编码器证明实际位移。

停止距离是从停止请求发出到车辆实际停稳的位移，和观察者看到车开始减速后的位移不同。先在低速、充分净空条件下准备正常停车测试；通信丢失/反馈过期等故障注入在阶段2专门安排，不能由用户随意拔电机线替代。250/500毫秒保护常量本身不证明停车距离足够。

## 5. 已有记录怎么复用

具体来源和迁移边界见[复用依据](reuse.md)。历史结果按“原安装/原固件的实测”“当前源码能力”“当前安装复核”分别标注。旧参数保留原来源，不自动覆盖新工程配置，不把旧日志的通过状态改为本次通过。

目前优先复核这些事实：49/50毫米两轴工作点、43毫米车载候选高度、三槽实际视野、雷达前方遮挡是否仍存在、机构145/107毫米报告的测量基准是否仍一致。完整内部相机标定和全套闭环增益不要求用户现在手工测出。

## 6. 回填与阶段出口

使用[测量记录](stage0_record.md)，第一轮只回填表中的A组前五项和现有连接情况；后续分批补齐，避免一次要求全部数据。

阶段0出口需要同时说明：

1. 收拢/载物轮廓、道路与转向空间有实测依据；两个启停区配置可复现。
2. 必要抓放高度、距离和过渡路径可达，三槽均有可用路径；完整可用行程和保留范围有独立记录。
3. 必要目标在实际相机姿态下可观察，雷达必要道路覆盖已确认，或明确列出尚未解决的盲区和替代观察位置。
4. 有代表性动作及导航耗时，而非仅依据RPM、指令时长或软件等待拼出的180秒承诺。可行性不足时指出具体瓶颈与调整项。

测量方案完成只表示阶段0准备完成。数据不足、未测或失败的项目保留原状态；阶段1独立通信软件可并行准备，但物理动作不越过对应验证条件。
