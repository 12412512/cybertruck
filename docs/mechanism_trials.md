# 机械实测流程与Web准备

本轮只完善PC网页、草稿及记录，不修改固件、不重启设备核心、不使能、不建零、不清故障、不触发实车动作。当前固件仍为GC-BASE-0.3.14，CAN故障待换PCB后验证。

## 当前Web可做

- 查看实时状态与动作被禁止的原因；轴、舵机、姿态使用中文阶段名。
- 在“实测准备与人工记录”选择执行器，查看对应流程，填入首次PWM同参考角、小步或回程目标。填入不发送命令。
- 记录独立尺量、角度、方向、抖动与停车观察；可导出JSON。本浏览器最多100条，域为manual_observation，physical_validated始终false，不增加真实抓放计数。网页联调记录明确标为未实测。
- 已保存实车姿态可以读取回草稿；选中版本与草稿不一致时阻止直接执行，须读取或另存版本。板端仍独立校验零点、版本、范围和互锁。

## 换PCB后的前置验收

1. 本次烧录/换板后重新检查板端版本、boot/session、CAN、停车、PWM及新反馈；不沿用历史验收。先完成只读稳定性窗口。
2. 本次现场确认后才允许开放site_ready；网页勾选不解除核心许可或CAN故障。
3. 核对ID5升降、ID6伸缩及三个PWM通道。人工最高/最近端基准，与独立固定标记对齐。
4. 在明确允许使能后逐轴使能；检查完整35/36/3A/33反馈和驱动配置。反馈不稳定不能建零。无实体限位，不使用软件命令碰机械端点。
5. 记录人工核对的料盘、转臂、夹爪真实参考角。这个步骤没有PWM输出，不以模拟锚点代替。

## 单轴：每段独立执行并复核

- 升降：初档5RPM，下降绝对目标2mm；目视方向、独立尺量、反馈到位和停车同时记录。通过后再独立回0mm。初期限程49mm保持，之后按实测分级扩展。
- 伸缩：先完成升降行程分级验收和转臂参考验收，转臂180°；升降到45mm并确认后，再以5RPM试伸出2mm。随后单独收回0mm；伸缩收回确认后才能升降回0mm。
- 不把命令目标、ACK或编码器换算值作为独立尺量值。超时、过期、反向、另一轴变化和CAN异常仍由正式固件停止；不为完成流程放宽保护。

## 舵机：首次PWM与后续小角度分开

首次目标必须等于当次人工核对的真实参考角；网页按钮只填草稿。明确允许后单通道输出，观察是否跳动、是否干涉，再人工确认。命令缓动/600ms等待不代表实际到位。

- 转臂：升降/伸缩均≤1mm。先验收当前参考；从已确认180°试175°再回180°。83°候选待完整包络核对。
- 料盘：升降/伸缩均≤1mm，转臂已确认180°，夹爪退出旋转区域。先同参考角，再从已确认0°试5°并回0°；30°、150°、270°分别验收三个料位。
- 夹爪：先空爪、同参考角。只有明确允许张爪时从已确认98°试93°再回98°；60°释放及真实夹持另验。停止保持夹持，不自动张爪。

0°为料盘基准，30°/150°/270°为三个存料位；不是四个料位。

## 姿态示教

1. 编辑完整五目标，保存新版本仅存草稿。
2. 从已保存版本读取，核对编号、版本、摘要和五目标；运行时修改输入不会改变冻结版本。
3. 先逐个完成三个通道首次PWM与人工确认。再选择收拢姿态的小幅单变化版本试运行，不能直接跳到完整取料姿态。
4. 开启逐步确认，每次只放行当前步骤；轴靠新反馈到位，舵机靠命令完成后独立人工确认。
5. 完整过渡仍由正式Pose预检与状态机执行；网页不是碰撞包络证明。异常时停止，保留部分完成状态，不自动重试、收臂或回零。

## 验证

`node tests/mech_guide.mjs`覆盖69项无网络/设备检查，包括故障、过期、现场许可、控制权、未应答、PWM前置、版本草稿比较与目标边界。浏览器仅验证填草稿、限制显示及人工记录；实车动作ID、零点和PWM不得改变。本轮不需要重新烧录。
