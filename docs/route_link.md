# 同会话短组合路线接入

2026-10-24，节点v0.16.0-route-link。当前板端GC-BASE-0.3.6支持所需四种单段，本节点新增树莓派多段调度、冻结路线接口和Web联调，不改底层控制算法、不再次烧录、不触发实车运动。此前未提交的90°与同步转姿增量并入本次较大节点。

## 已实现

- config/short_route.json冻结“前进100mm→前左60/60mm→固定朝向小弧线→前进60mm同时逆时针10°”。正式RefSpec与C参考采样生成预览，末端名义坐标约(300.15,140.15)mm/+10°，不是场地地图坐标。
- drive_core复用原会话/保活/执行状态机，仅建立一次OPEN、CONFIG和ARM，动作ID递增，整个路线不重置odom。下一段只在上一段Track完成、低速及稳定屏障满足后接收；最后统一STOP并核对停止。不以发送完成代替到位。
- 当前位置可为已有非零odom，首次目标前冻结实际起点，将名义参考作SE(2)转换；不为对齐画面清零里程计。每段仍相对该段实测起点执行，因此展示累计偏差，不宣称全局绝对路径跟踪。
- 段间目前停车稳定交接，保持会话与里程连续；尚未实现跨段非零速度的平滑交接。原8000整场模型的连续弯道/转姿窗口保留为模拟能力。
- 异常、超时、丢GOAL应答或boot/session变化均停止，不重发、不重连续跑、不自动重新使能。四段总体期限90秒，各段原20秒期限及板端保护不变。物料状态和成功计数不受本路线影响。

## 与8000整场模拟的关系

route_sim直接导出规划器已有的RefSpec88，不复制曲线或另建规划器。当前8000整场方案导出9段、map坐标、domain=simulation、executable=false。仅导出意味着数据接口接通，不表示地图已配准或已允许整图执行。

短组合的入场验证只允许本轮固定目标、同一参数、odom坐标和摘要。整场包、改过的目标、错误摘要，在任何串口写入之前拒绝。不能把整场速度直接下发，也不能用关闭保护绕过部署条件。

Web新增短路线面板：名义参考、反馈轨迹、朝向、段进度和最终停车状态。8000的“播放离线闭环”使用明确标记的模型记录，以2倍速回放，不打开设备；8081可显示同格式实车执行状态。旧整场模拟图保留，新增统一轨迹导出状态。

API仅GET/WS：/api/routes/short提供冻结短路线，/api/routes/short/replay提供匹配版本的模拟记录，/api/routes/field提供规划器导出包。无网页运动POST。执行反馈过期时撤销当前路线位姿，只保留标明历史的轨迹；不会把旧图当成实时位置。
