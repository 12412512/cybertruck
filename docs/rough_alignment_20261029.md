# 粗加工区先微调、后动作标定

2026-10-29用户调整优先级：先实现粗加工区到位微调，再集中标定机械动作。此文覆盖field_plan_20261029中先完整机械短闭环、后微调的顺序。

## 目标

粗停→进入固定相机观察姿态→识别2号圆环及可见辅助圆环→底盘局部修正→停车后重新观察→重复到位→用户标定机械动作。首先只处理2号位，后扩展1、3号位。不要求先完成三槽取出/完整放置流程。

停靠重复性与夹持中心准确性分别验收。可先用经人工确认可达的停靠位置作为暂定参考验证返回能力；之后只需一次实际夹持中心/放置位置核对并更新参考，不必先测完整机械流程。任何参考变更须增加版本，不能继续沿用旧参考下的机械标定。

## 代码核对结果

- pi/robot/vision/legacy/alignment_vision/core.py已有编号圆环稳定观测、参考图像坐标、辅助环方向及间距变化，明确metric_valid=false、vehicle_yaw_valid=false、action_allowed=false；这些是图像量，不直接等同底盘位移/航向。
- 旧工程Pi/align_micro/core.py有MicroExperiment、停车时间屏障后的新帧采样、标定审查和小步预览。优先复用设计与算法，不能沿用旧安装姿态的数值矩阵，也不能另开串口运行旧link。
- 当前capabilities.py中.44具备诊断能力，但physical_motion为空。不能只改白名单开放底盘。
- 当前MechPort_Owned返回attached；base_port.c对附着机构拒绝底盘配置/使能/目标。其静止查询在EXEC_READY/ACTIVE退出；bus.c活动查询只轮转四轮速度/位置。因此仅删互锁会使两轴反馈缺失，不能当作修复。

## 实现及验收顺序

1. 固定观察姿态合同：两轴位置、三个舵机命令与实物确认、零点/版本、相机身份/配置/分辨率、工位/圆环号/地面平面。昨日夹爪0/60/95度画面分开；不能挑一张直接当统一基准。
2. 复用旧识别及参考管理，给出新鲜帧的像素偏差；先离线回放，缺帧、遮挡、错号、姿态或参考版本变化时不输出修正许可。辅助圆环不足时不能冒充航向已验证。
3. 在同一设备核心补微调请求和执行权交接；底盘动时机构保持固定，保持六节点反馈、零点及PWM，不同时执行抓放。由固定观察姿态合同约束微调，不把运输收拢姿态合同直接套用。
4. 联合离线验证调度、停止、应答丢失、重复请求和反馈超时；必要的固件更新编译后先通知用户，烧录及实物验收沿用约定。不得把通用机械手动免轮速当成正式交接许可。
5. 实物采用已知底盘小位移核对正负方向及局部比例；每次运动完成并确认停车后采新帧。物料移动与底盘移动的方向不能混用，昨日手摆约25mm或ID6动作不直接生成底盘毫米矩阵。
6. 从不同前后/左右小偏差回到同一2号环参考，至少3次独立回位，检查最终实体位置、偏差趋势、动作次数及耗时；超出标定范围不硬套矩阵。收敛后固定参考版本。
7. 用户基于该参考集中标定2号位机械流程，助手读取保存版本；然后扩展1/3号位及三车载槽。机械动作结束必须恢复规定观察姿态再进行下一次视觉到位检查。

## 0.3.45离线候选

后续补齐了以画面中心为目标的自动循环、后台圆环订阅和四向采样记录；见rough_centering_20261029.md。下述“自动修正未开放”仅指实车未加载本车已验收矩阵，不再表示运行状态机尚未实现。

当前已经实现固定观察姿态的MECH→BASE小位移→MECH交接，复用原Base/Exec/Track、唯一Bus和MechanismLink。板端71号执行准备/提交/取消/返回，72号读取交接代次；主机Arrival与现有机械页共用控制权、续约和停止，不另开串口。合同引用未删除联调版本的ID/修订/SHA/检查点，累计计算两轴与三舵机目标，缺项不补0，并绑定本次零点和会话。它只表示空爪固定观察位，不是持料运输或整场路线许可。

活动底盘调度同时更新四轮与ID5/6，维持匹配回包、轴发送10ms/接收12ms冷却及250ms反馈保护。交接时沿用手动1mm终点档，冻结实际两轴位置，后续漂移独立限制±0.5mm；三路PWM维持原命令，机构动作拒绝插入。正常返回结束底盘活动批次并补齐停车反馈，不调用STOP、重开串口或重建零点。正常返回清空本轮PC0票据；再次试验必须新合同并重新按PC0，旧票据不能启动。

配置10仅在有效交接内开放：固定车头、每步单轴±1～5mm、最高10mm/s、轮速上限6RPM，PC0短鸣后仍须明确点击方向才运动。每轮最多20步；不是180秒正式任务的速度限制。没有开放.45底盘整场跑图白名单。Web同页增加圆环观察和候选参考保存，避免为了看图退出机械控制页；参考保存只接受静止阶段的新鲜稳定图。候选参考图不等于夹持中心已经标定。

旧工程Pi/align_micro/core.py的矩阵审查与小步预览已迁入vision/arrival.py；它要求姿态摘要、视觉配置、当前停车屏障和停车后新帧一致，输出仍明确motion_authority=false。离线组合验证已经把像素偏差预览接入同一个Arrival小位移报文生成器。真实安装下的方向、比例和回位重复性尚未测量，因此网页自动视觉修正保持关闭，不能把合成矩阵作为实车参数。
