# 代码与文件风格

## 基本要求

手写代码保持简洁、中文注释、命名清楚、排版有逻辑。生成代码保留厂商原注释与许可证，不为统一风格批量改写 HAL 或 CMSIS。

文件使用 UTF-8；同一模块的 `.c/.h` 放在一起。C 使用 4 空格缩进和独占行花括号，Python 使用 4 空格缩进。

## 命名

公共 C 接口采用“模块名_简短动作”：

```c
void App_Init(void);
void App_Run(void);
void Base_Stop(void);
```

公共类型使用明确模块前缀，常量采用大写下划线；私有函数声明为 `static`。局部变量命名直观，不用难以解释的拼音或随意缩写，单位必要时进入名称，例如 `speed_rpm`、`age_ms`、`pos_mm`。

Python 模块和函数使用小写下划线，通过正常包导入，不拼接旧工程路径。

## 组织与注释

- 文件按包含项、常量与类型、私有状态、私有函数、公共接口组织；依赖方向由上层到下层。
- 一个函数承担一个明确职责；不为短小而叠加无意义包装层，也不把完整业务塞入长函数。
- 一行一个主要操作，保留有意义空行；相关分支按处理顺序排布。
- 注释写清用途、单位、前置条件和限制。避免“变量加一”之类复述语句的注释。
- 共享状态明确唯一写入者；跨中断访问说明原子性与同步方式。

## 执行约定

- 裸机周期调度使用非阻塞状态机。周期函数快速返回，不用长等待维持动作。
- 中断负责搬运数据、记录状态与置事件，业务解析在主循环中执行。
- 初始化不等于启动执行，最小工程不自动启动 PWM、不使能电机、不发送运动命令。
- 对外动作必须表达接受、运行、完成、失败、取消；通信发送成功不代表物理动作完成。
- 参数集中到归属模块，写明单位、来源与有效范围；不把未经确认的旧参数当作新硬件验收结果。

## 生成代码保护

应用代码放 `User/`。CubeMX 生成文件内仅在 `USER CODE` 区保留必要的头文件与最小入口调用，目标形式为初始化末尾 `App_Init()`、循环内 `App_Run()`。

更改 `.ioc` 后重新生成，检查用户区、时钟、GPIO、电平、IRQ、工程引用及相应编译。生成通过与编译通过分别记录。
