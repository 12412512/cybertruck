# Control

底盘、双轴、机构姿态和动作确认。当前文件均为底盘纯计算库：

| 模块 | 职责 |
| --- | --- |
| `kin.c/.h` | 麦克纳姆正逆运动学、四轮同比限幅 |
| `yaw.c/.h` | 连续航向展开、时间历史插值与异常锁存 |
| `curve.c/.h` | 标量静止到静止七段S曲线；显式速度/加速度/加加速度限制 |
| `line.c/.h` | X/Y/任意斜线共用时间轴，两轴同步起停 |
| `path.c/.h` | 带余弦曲率过渡的90°弧线几何、缓存导数和反馈边界投影 |
| `odom.c/.h` | 异步四轮共同时间区间、IMU历史、连续本地位姿与异常锁存 |

各模块不依赖HAL，不含车辆默认几何，不发送电机命令，不在App中调用。参数和滚子排列需明确提供；实际电机极性、IMU单位/符号由后续设备边界适配。纯计算测试不代表底盘闭环或里程计已实现。

`Path`描述几何，`Curve`提供静止到静止及最多15相位分段变速时间轴。`Ref`已接线段、切线弧、连续弯道、同步移姿及安全转姿窗口，给出笛卡尔/角速度、加速度、jerk；`Track`负责同一正式跟踪与稳定到位。上位机名义地图进一步检查轮速和保守扫掠，详见`docs/flow.md`。各层仍仅计算/主机模拟，禁止直接接电机后称为实车弧线闭环通过。

来源、测试与未验证项见`docs/motion_readonly.md`；计划均由唯一动作所有者冻结，参考结束和边界投影不作为实物到位证据。

连续观察器进一步见`docs/odometry.md`。它复用轮增量、时间历史和整批提交，并先对齐四轮共同时间边界，按轮/IMU历史节点分段积分；不按动作清零、不外推、不用轮航向重复校正IMU。配置必须显式给轮位、极性、比例、IMU换算及连续性代号，无本车默认参数。主机导出宏只控制Windows模型符号可见性，不改变STM32入口或算法。

`Ref_TurnSpeed`按真实航向插值时段对分段速度多项式求极值，为上位机轮速预检提供保守界，避免叠加不同时刻峰值；全程扫掠仍用`Ref_Bounds`。该查询不改变运动输出、V/A/J限制或App调用，详见`docs/speed.md`。
