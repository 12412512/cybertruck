# Device

电机协议、IMU、屏幕、按键和蜂鸣器等设备模块。通过 Board 访问硬件，不重复占用外设。

当前`stamp.c/.h`为MCU接收/处理时间、序号、连续性和回绕检查；`motor.c/.h`只解35/36/3A回复，不含构帧、使能、停止或运动；`imu.c/.h`为单消费者11字节解析器，保留三轴原始值、原始帧和首末字节时间，固定16槽队列。

现已通过Board接入App：port负责USART2字节与时间，can_tx负责唯一CAN环，bus在主循环唯一调度/解析；drive复用旧电机构帧协议，不重复启用外设。配置前可只读导出原始样本；执行器显式绑定配置时当前有效IMU代，之后换代即中止。接收时间不等于设备内部采样时刻；IMU量程、安装方向及轴符号仍待验证，不在此层自动换算为已标定位姿。

队列记录可能属于旧代，读取后必须检查`Imu_Valid`；UART错误、源变化、坏帧、长间隙或溢出改变连续性，不能将旧样本改贴新代。`Imu_Tick`仅在接收积压已排空后调用。时间规范见`docs/feedback_time.md`。
