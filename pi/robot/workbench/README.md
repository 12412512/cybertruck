# 工作台离线核心

本目录负责工作台输入契约、控制权、命令去重、后台规划和离线执行适配。
网页通过回环HTTP访问此核心；核心没有串口、SSH或烧录入口。

| 文件 | 职责 |
| --- | --- |
| `contracts.py` | 输入单位、范围及机械扩展状态契约 |
| `planning.py` | 复用拓扑规划器与正式C参考，按场景重新选路 |
| `scene.py` | 工位间隙、障碍物及名义地图的场景构建 |
| `storage.py` | 工作区、保存版本和配置校验摘要 |
| `simulation.py` | 正式C跟踪器、连续里程计与独立合成车体 |
| `service.py` | 唯一控制权、点动期限、去重、版本和日志 |
| `core.py` | 独立进程入口及100Hz模型调度 |

启动方法、已验证范围和后续设备接入见 `docs/workbench.md`。
正式实现不从 `tools/` 或 `tests/` 导入代码。
