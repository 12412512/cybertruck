# 树莓派程序

本阶段仅建立结构，不移植或运行旧程序。

后续唯一启动入口为 `robot/main.py`，任务状态机为 `robot/task.py`；二者尚未实现。

| 目录 | 职责 |
| --- | --- |
| `robot/device/` | 唯一 STM32 串口管理、相机及雷达设备管理 |
| `robot/nav/` | 地图、A*、定位估计与路径执行 |
| `robot/vision/` | 扫码、物料、圆环和结果确认 |
| `robot/web/` | 网页接口与页面资源 |
| `deploy/` | 服务启动和部署配置 |

树莓派维护唯一任务与计数账本；网页不直接打开串口。包导入不依赖旧工程路径。
