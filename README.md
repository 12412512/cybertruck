# 工创搬运小车

树莓派负责感知、规划、任务调度及网页控制台，STM32F407ZGT6 负责底盘、机构、反馈和保护。本仓库从空目录建立，旧工程仅作为后续迁移参考。

## 当前阶段

已推进到两批连续导航模拟：启停区1车头+X、启停区2车头−X、扫码+X，蓝区可通行，取消X优先路线。带朝向A*直接选择平移转姿、连续弯道和低速转姿窗口，复用旧分段变速算法和正式C跟踪器。154项主机回归通过；本轮见[连续导航与预算](docs/flow.md)，前序[导航节点](docs/navigation.md)、[轨迹跟踪](docs/tracking.md)、[连续里程计](docs/odometry.md)及[CAN与时间链](docs/feedback_time.md)保留。

Keil三项基线及本机`.uvoptx`保护保持通过；本机818项静态检查、编译后复查通过，Keil完整重编译0错误、0警告。新增跟踪器未接入App；本轮HEX与上节点相同，产物与未用段证据见本轮记录。

新工程App只调度USART1只读协议；CAN和PWM不启动，PC0只上报原始输入。前序已核对真实串口由Pi旧服务独占，新观察核心通过GET读取已有缓存；本轮不重复旧节点现场检查、不另开串口、不烧录、不触发运动。实车GC时间字段及标定尚未接入，模型位姿和计数不填入真实状态。

新只读实车页为`http://127.0.0.1:8001/`，原Pi8080保持运行。[Web合并安排](docs/web_merge.md)采用新FastAPI统一入口，优先复用旧成功模块，先合并状态诊断，后续按保护出口接运动。历史[通信离线验收](docs/stage1_readonly.md)、[Keil修复记录](docs/keil_base.md)、[基础验收](docs/baseline.md)保留。

本机`http://127.0.0.1:8000/`显示8段两批跨区导航、参考/模型轨迹、车身朝向及到位证据。启停区1同为0.14m/s时由170.34s降至135.46s，28次停车段减为11次，独立原地转向由10次降至0次。当前未含工位内移位和视觉修正，完整60秒预算未通过；原点位置、完整外形仍待测，真实pose/count未知，既有模拟成功账本与导航分开。

前序CAN排查记录了停止帧发送期间的ACK异常及FAULT锁存，电气根因未确定；该节点的窗口证据保留在CAN记录，本轮不据旧快照推断当前硬件状态。旧HTTP没有完整源接收时刻，真实observer精确反馈时间仍未知；新时间负载未接实车在线调度，不得将离线模型视为真实导出通过。

整机升级已进入阶段0测量准备：按[测量方法](docs/stage0_measurement.md)分批完成断电静态尺寸、只读观测和后续受控动作，使用[回填记录](docs/stage0_record.md)保存结果。旧模块按[复用依据](docs/reuse.md)核对后迁入；当前尚未完成阶段0实测出口。

## 生成与编译

在工程根目录使用 PowerShell 执行：

```powershell
.\tools\generate.ps1
.\tools\build.ps1
```

生成脚本先由CubeMX加载`.ioc`并生成代码，再同步Keil工具链与按职责分组的手写文件，最后执行当前只读阶段检查。编译脚本执行检查和完整重编译，不下载、不进入调试。主机回归入口为`tools/test.ps1`。

产物位于 `firmware/MDK-ARM/Objects/`，日志位于 `output/`，均不纳入 Git。工具路径覆盖参数与单独检查命令见[工具说明](tools/README.md)。

## 开发约定

- 开始工作前阅读根目录 [AGENTS.md](AGENTS.md)。
- 硬件连接与参数见[接线基线](docs/wiring.md)；分层与运行职责见[整体架构](docs/architecture.md)；命名和排版见[代码风格](docs/style.md)。
- CubeMX 生成文件与手写代码分离。生成区之外不手改生成代码，重新生成后必须检查差异并重新编译。
- 验证区分配置检查、编译、通信、实物动作及完整任务；每项只声明本次实际完成的范围。
- 本地 Git 保存关键节点，提交时写明验证范围并打带说明的标签；不自动推送远程。

## 后续实施顺序

阶段0实物与时间可行性 → 阶段1实机只读通信 → 底盘/IMU → 机构与调试台 → 视觉几何 → 地图定位与规划 → 导航精对准 → 单件/第一批 → 两批码垛返航 → 时间与精度优化。独立通信软件已按用户授权与阶段0并行准备。

任何硬件动作都必须有对应阶段的明确授权；本次建立工程不包含这些动作。
