# 工创搬运小车

树莓派负责感知、规划、任务调度及网页控制台，STM32F407ZGT6 负责底盘、机构、反馈和保护。本仓库从空目录建立，旧工程仅作为后续迁移参考。

Keil三项基线及本机`.uvoptx`保护保持通过；本机818项静态检查、编译后复查通过，Keil完整重编译0错误、0警告。新增跟踪器未接入App；本轮HEX与上节点相同，产物与未用段证据见本轮记录。

新工程App只调度USART1只读协议；CAN和PWM不启动，PC0只上报原始输入。真实串口由Pi旧服务独占，新观察核心通过GET读取已有缓存。弯道版完成后已按用户确认进行只读上电核对及一次架空单轮请求，提前停止并取得新停车反馈；未烧录或落地跑图。用户要求跳过逐轮重复检查，后续沿用旧Web配置并在短段试行中合并验证，见[复用依据](docs/hardware_reuse.md)及[实测记录](docs/field_test.md)。实车GC时间字段及标定尚未接入，模型位姿和计数不填入真实状态。

新只读实车页为`http://127.0.0.1:8001/`，原Pi8080保持运行。[Web合并安排](docs/web_merge.md)采用新FastAPI统一入口，优先复用旧成功模块，先合并状态诊断，后续按保护出口接运动。历史[通信离线验收](docs/stage1_readonly.md)、[Keil修复记录](docs/keil_base.md)、[基础验收](docs/baseline.md)保留。

本机`http://127.0.0.1:8000/`运行0.30m/s直线、1.2rad/s弯道/窗口模拟档。起点1两批跨区94.77→84.29s，起点2为100.33→89.41s并减少1个停车；仍保留工位停车和新反馈稳定到位。返航只需停入所选区，不要求原中心点或朝向。尚缺工位内移位和视觉修正，完整60秒预算未通过；准备计算单独记录。300mm已澄清为杆件长度，完整包络仍待测；实车位姿、标定和成绩未验收。

## 生成与编译

在工程根目录使用 PowerShell 执行：

```powershell
.\tools\generate.ps1
.\tools\build.ps1
```

生成脚本先由CubeMX加载`.ioc`并生成代码，再同步Keil工具链与按职责分组的手写文件，最后执行当前只读阶段检查。编译脚本执行检查和完整重编译，不下载、不进入调试。主机回归入口为`tools/test.ps1`。

产物位于 `firmware/MDK-ARM/Objects/`，日志位于 `output/`，均不纳入 Git。工具路径覆盖参数与单独检查命令见[工具说明](tools/README.md)。

## 开发约定

- 开始工作前阅读根目录 [AGENTS.md](AGENTS.md)。
- 硬件连接与参数见[接线基线](docs/wiring.md)；分层与运行职责见[整体架构](docs/architecture.md)；命名和排版见[代码风格](docs/style.md)。
- CubeMX 生成文件与手写代码分离。生成区之外不手改生成代码，重新生成后必须检查差异并重新编译。
- 验证区分配置检查、编译、通信、实物动作及完整任务；每项只声明本次实际完成的范围。
- 本地 Git 保存关键节点，提交时写明验证范围并打带说明的标签；不自动推送远程。

## 后续实施顺序

阶段0实物与时间可行性 → 阶段1实机只读通信 → 底盘/IMU → 机构与调试台 → 视觉几何 → 地图定位与规划 → 导航精对准 → 单件/第一批 → 两批码垛返航 → 时间与精度优化。独立通信软件已按用户授权与阶段0并行准备。
