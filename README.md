# 工创搬运小车

树莓派负责感知、规划、任务调度及网页控制台，STM32F407ZGT6 负责底盘、机构、反馈和保护。本仓库从空目录建立，旧工程仅作为后续迁移参考。

## 当前阶段

前进100mm、左移80mm、逆时针10°已分别完成实车初测，用户确认方向正常并已停，CAN错误均为0。板端记录约102.74mm、82.45mm及10.102°；距离未尺量、角度仅目测，不作为精度标定。见[短段实测](docs/short_trials.md)。当前执行核心已退出、串口已释放，实车页会显示状态过期；下一步短斜线与弧线，尚不跑整图。

GC-BASE-0.3.3已烧录，103,568字节有效内容逐字节读回一致。30秒只读验收通过：未配置/未使能、启动停车确认、四轮0 RPM、CAN新增5,994帧且零错误、两路UART零错误，IMU时间链持续更新。详见[板端验收](docs/board_readonly.md)。本次没有下发CONFIG/ARM/GOAL或触发轨迹。

实车只读页为[树莓派8081](http://172.20.10.4:8081/)，核心独占串口，网页不控制设备；旧8080服务已停用并关闭自启。本轮只读观察已停止以让位单段测试，核心不自动恢复运动。本机[8000](http://127.0.0.1:8000/)继续离线模拟。

目前处于阶段2，三个基础方向已初测，后续仍需独立尺量与重复性验证；触发后续动作前先告知用户，不重做单轮测试。原始IMU顺时针增加，配置v2采用yaw_sign=-1；实体方向响应、比例、距离精度仍待短段验收。见[执行接入](docs/execution.md)。

弯道模型复用正式S曲线、几何导数限速与扫掠检查，固定0.30m/s、1.2rad/s候选档，两批跨区起点1为84.29s、起点2为89.41s；不含完整工位移位与视觉修正，60秒预算尚未通过。见[弯道与转姿](docs/corners.md)、[提速](docs/speed.md)、[连续导航](docs/flow.md)。模拟地图executable=false，不能直接用于实车跑图。

阶段0仍缺完整包络和机构耗时，300mm已确认为杆件长度，不能当作整车宽度。测量使用[方法](docs/stage0_measurement.md)与[回填记录](docs/stage0_record.md)。底盘、机构、视觉与完整任务仍按阶段出口推进；既有[只读通信](docs/stage1_readonly.md)、[CAN与时间链](docs/feedback_time.md)、[里程计](docs/odometry.md)、[跟踪](docs/tracking.md)、[复用依据](docs/reuse.md)保留历史证据。

## 生成与编译

在工程根目录使用 PowerShell 执行：

```powershell
.\tools\generate.ps1
.\tools\build.ps1
```

生成脚本先由CubeMX加载`.ioc`并生成代码，再同步Keil工具链与按职责分组的手写文件，最后执行当前只读阶段检查。编译脚本执行检查和完整重编译，不下载、不进入调试。主机回归入口为`tools/test.ps1`。

产物位于 `firmware/MDK-ARM/Objects/`，日志位于 `output/`，均不纳入 Git。工具路径覆盖参数与单独检查命令见[工具说明](tools/README.md)。

## 开发约定

- 开始工作前阅读根目录 [AGENTS.md](AGENTS.md)。
- 硬件连接与参数见[接线基线](docs/wiring.md)；分层与运行职责见[整体架构](docs/architecture.md)；命名和排版见[代码风格](docs/style.md)。
- CubeMX 生成文件与手写代码分离。生成区之外不手改生成代码，重新生成后必须检查差异并重新编译。
- 验证区分配置检查、编译、通信、实物动作及完整任务；每项只声明本次实际完成的范围。
- 本地 Git 保存关键节点，提交时写明验证范围并打带说明的标签；不自动推送远程。

## 后续实施顺序

阶段0实物与时间可行性 → 阶段1实机只读通信 → 底盘/IMU → 机构与调试台 → 视觉几何 → 地图定位与规划 → 导航精对准 → 单件/第一批 → 两批码垛返航 → 时间与精度优化。独立通信软件已按用户授权与阶段0并行准备。

任何硬件动作都必须有对应阶段的明确授权；当前授权与现场验收范围见板端记录。
